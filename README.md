## 🇬🇧 English

> **Course:** Graphic Design · Course project

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> About the Project
A modern redesign of the **Samsun University Software Engineering department** website, made as the Graphic Design course project. The site presents the department, its academic staff, research and student life with a clean, responsive layout.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Pages
* 🏠 **Home** — hero section, research areas and a call to join the department
* ℹ️ **About** and 👩‍🏫 **Faculty Members** (with staff photos)
* 📚 **Courses**, **Programs** and **Faculties**
* 🔬 **Research** and **Labs**
* 📰 **News** and 📢 **Announcements**
* 🎓 **Admission**, **Internship**, **Career** and **Alumni**
* 🎉 **Student Life**, **Library**, **International** and ✉️ **Contact**

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Tech Stack
React 19 · TypeScript · Vite · Wouter (routing) · TanStack Query · Tailwind CSS · Radix UI (shadcn/ui)

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Running
```bash
npm install
npm run dev
```

## 🇹🇷 Türkçe

> **Ders:** Grafik Tasarım · Dönem projesi

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> Proje Hakkında
Grafik Tasarım dersi proje ödevi olarak hazırlanmış, **Samsun Üniversitesi Yazılım Mühendisliği bölümü** web sitesinin modern bir yeniden tasarımıdır. Site; bölümü, akademik kadroyu, araştırmaları ve öğrenci yaşamını sade ve duyarlı (responsive) bir düzenle sunar.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Sayfalar
* 🏠 **Ana Sayfa** — giriş bölümü, araştırma alanları ve bölüme katılım çağrısı
* ℹ️ **Hakkımızda** ve 👩‍🏫 **Akademik Kadro** (fotoğraflı)
* 📚 **Dersler**, **Programlar** ve **Fakülteler**
* 🔬 **Araştırma** ve **Laboratuvarlar**
* 📰 **Haberler** ve 📢 **Duyurular**
* 🎓 **Aday Öğrenci**, **Staj**, **Kariyer** ve **Mezunlar**
* 🎉 **Öğrenci Yaşamı**, **Kütüphane**, **Uluslararası** ve ✉️ **İletişim**

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Teknoloji Yığını
